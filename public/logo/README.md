# PharmaTrack Custom Logo Folder

Place your custom logo file (e.g. `logo.png`, `logo.svg`, `logo.jpg`, or `logo.webp`) inside this `/public/logo/` folder.

### Instructions to apply your custom logo:
1. Upload or save your logo file in this directory as `/public/logo/logo.png` (or your preferred image name).
2. In PharmaTrack, navigate to **Settings** -> **Pharmacy Profile & Identity**.
3. Use the **Upload Logo** file picker to select your image, or enter `/logo/logo.png` into the Logo URL input.
4. Click **Save Settings**. Your custom logo will instantly replace the default green pill icon in the sidebar and header!
